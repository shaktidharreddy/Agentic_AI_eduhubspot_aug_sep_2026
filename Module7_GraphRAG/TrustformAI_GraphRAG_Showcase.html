Why the premise matters

“If no, are you planning on implementing a DLP tool in the next 12 months?” means nothing without the answer to “Do you currently have DLP tools installed?”. A vector store ranks rows one at a time and can hand the model the follow-up alone. The graph stores the link and adds the premise.

One store, two kinds of search

Similarity search and graph traversal run in the same Neo4j query. The embeddings live on the Answer nodes, so there is no second database to keep in step with the first.

Every answer leaves a trail

Each drafted answer can be stored with the rows it was built from, their rank and similarity, and whether they reached the prompt. “Why did we say this?” still has an answer next quarter.
